There's nothing immediately special about the cover image of this blog post, but there is a cool part about it which will only become apparent with my sites newest feture.
The theme switcher slash light/dark buttons. Go ahead and toggle the theme to see what I mean.
![This posts cover image](/src/assets/images/blog/eclipse/64cef3896414a42f4a0d83ae2cbdb803c94a9613da0a1a02dc1d9a85663f49bb.png)

I like images like these a lot, and I've been meaning to make a blog post about them for a while now.
It took me way too long to figure out how to make the theme switcher work, but now that it's done it's time to share more of these images.  
I have a bunch of these down below and I've set the `background-color` of each image to fully white or fully black depending on the current theme, and a nice 0.3s transition.
I recommend to keep light mode on when scrolling onto new images, and then toggle to dark mode to see the effect.
