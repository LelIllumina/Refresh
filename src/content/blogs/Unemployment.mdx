## Bot

Before I go into the details of why exactly the job sucked, I'd like to talk about the bot itself because it'll be used on the job later on as well.

The specifics of what the bot needed to do were left quite brief by “A”. Very basically, all it needed to do was:

1. Be on Telegram
2. Respond to messages sent to it by a user using AI.

I spent a day or two of looking at Telegram bot libraries and trying to find a way to use AI using API calls for free. After settling on 2 main libraries, I made a simple bot using Telegraf for the bot code and used Groq (not to be confused with Grok) for the AI responses.

One of the most annoying issues with the bot was actually the fact that Telegram is banned in my country. To get anything to work, including my Telegram account and the bot’s API calls I needed to use a VPN. This was wholly very annoying as it made everything slower.

### Telegraf

Telegraf is a JS/TS bot Library for Telegram and was simple enough to use with the boilerplate code it provided, but alas this would bite me in my ass in the future, but here is mostly my fault.

I had a little experience with Discord.JS so using the bot library wasn't super hard at first, if it hadn't been me using Typescript for whatever reason, which caused me quite a few headaches further on. Besides that, Telegraf itself didn't really have much documentation other than the README which had some basic starter code and examples. The reason was that most libraries like these are just wrappers for API requests on the platform the bot is of (i.e., Discord, Telegram, etc.), so the methods and functions in the library are structured to match those API endpoints. This basically means you need to use both the library and the platform's documentation to understand how to do something besides basic stuff you might infer from the README.
This wasn't really anyone's fault besides mine, I just hate reading documentation, but I did eventually read a bunch of the Telegram bot docs and implemented what I needed to, more on that later.

### Groq

Unlike official Web UIs for AI chatbots like ChatGPT or Claude, using these services anywhere else requires you to acquire an API key. Also, unlike official Web UIs, these API keys are not free. You might have free credits or a free trial, but long term you'll need to pay up.

That's where I found Groq and its free API. I'm not a 100% sure on what exactly their vision or policy is, but they seem to focus on making their model's “Inference” faster. Inference here meaning the AI model actually doing the AI writing. They have really slimmed down and efficient models, which makes them faster and more importantly cheaper to run. This amounts to them giving registered users, albeit on a pretty low rate limit, free access to models using their API.  
This allowed me to both prototype and actually develop and deploy the bot using Groq’s AI responses.

Overall, I had around a week's worth of time, but I just slacked off for most of it.
